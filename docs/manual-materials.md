# 人工验证素材使用说明

解压 manual-verification.zip。01-valid 内是6张可正常上传的网络照片；02-invalid 内是4个刻意无效的校验文件，请勿当作正常素材。来源与授权见 SOURCES.md。

## 正常制作

1. 打开 http://localhost:3000/ ，日光肖像上传 01-hiker.jpg（也可换成04-flower.png）。确认预览、替换、移除均正常；提交后查看阶段更新、成功PNG和制作记录。
2. 旅行明信片依次上传 02-lake.jpg、03-shore.jpg。调整标题、配色、比例和两张图裁剪，确认预览与下载结果一致。缺少一张时不能提交。
3. 周末拼贴依次上传 04-flower.png、05-coffee.jpg、06-forest.png，确认图片顺序和成品顺序一致。
4. 批量制作增加以上三个模板，共需6张图；检查素材就绪项数/图片数，准备齐全后再提交。提交后离开页面，回到批次与制作记录查看是否继续更新。
5. 完成一次制作后刷新页面，确认历史记录仍在；尝试收藏、改名、标签、隐藏/恢复、ZIP下载。游客记录依赖当前浏览器，避免测试中清Cookie。

## 输入拒绝

- 01-too-large.jpg：5 MiB + 1 字节，应提示文件过大。
- 02-too-many-pixels.png：4500×4500（2025万像素），文件很小但应因像素数过多被拒绝。
- 03-corrupt.jpg：扩展名为JPG，内容不是图片，应提示图片损坏/无效。
- 04-unsupported.txt：非图片，应提示只支持JPEG/PNG；若文件选择器默认隐藏它，请选择“所有文件”。

错误后应能重新选择正常照片，不能残留旧预览或错误地启用提交。请勿把异常文件全部上传到个人长期素材中。

## 身份与账号（可选）

游客可直接制作；注册账号会保留当前游客记录。新密码8～18位，恢复码只显示一次，需要自己保存。若只想验证图片功能，无需注册或改密码。

## 记录结果

每项记录“通过/失败”、浏览器、复现步骤与截图；制作失败时记录任务编号和提示。应用是本地模拟制作，不调用真实AI生成服务。本文提供测试步骤，不代表这些人工步骤已由用户执行。
