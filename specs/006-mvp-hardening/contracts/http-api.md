# 006界面与验收契约

不增加或改变Java端点。GET /api/jobs分页沿005；刷新成功替换当前nextCursor，失败保留旧游标，旧任务合并规则沿005。

成功结果仍GET /api/jobs/{id}/result，携带同源cookie。用户点击“重新加载图片”后追加previewAttempt整数query并重新挂载图片；代理原样透传query，Java忽略该资源重读标记，不产生任务。重试中按钮暂时移除，显示“正在重新加载图片…”，load后显示正常图片；error后提示“结果图片加载失败，制作状态仍为成功。”并恢复重试入口。
不同任务的图片资源错误互不影响。失败/未就绪任务不显示结果重试。图片404、网络错误均不改变制作终态。

受理测量仍POST /api/jobs，单图片模板、默认三阶段各2000ms；202且新job.id可见，小于2000ms目标。明确API可用编号与浏览器观察到编号两种数据，不在产品界面增加测量参数。
