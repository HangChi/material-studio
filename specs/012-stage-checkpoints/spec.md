# Feature Specification: 阶段断点续跑
**Created**: 2026-10-30
**Status**: Ready
**Input**: 第10项第一独立增量：已完成阶段不因暂时失败或重启重复计算。

## User Scenarios & Testing
### US1 中断后复用已完成工作（P1）
制作已完成图片合成但尚未整理结果，服务中断后，同一作品继续整理，保留历史并减少重复计算。
验收：给定有效的合成断点，恢复后合成只执行一次；只有素材检查断点则只重做合成及整理；旧作品无断点仍能从头恢复。
### US2 失效断点安全回退（P1）
断点产物缺失、损坏或输入变化时，不发布旧内容，退回可验证的阶段；原有取消、失败和执行上限保持。
验收：删除/改写中间文件后重新合成；素材内容/配方变化后旧断点不可复用；取消后不发布成功；最多三次执行；查询不推进制作。
### Edge Cases
写文件后数据库事务失败允许留下孤儿但不得承认已完成断点；恢复时不相信仅存在的文件；不跟随符号链接。模拟指定阶段失败保持确定性、不自动重试。

## Requirements
- FR-001 素材检查和图片合成完成后保存输入摘要及阶段完成标记；合成中间产物具有内容摘要。
- FR-002 只有输入/产物均匹配时复用，缺失/损坏回退到最近有效断点，保持同一任务编号和递增事件版本。
- FR-003 阶段完成与断点登记共同提交，未提交产物不可复用；成功/永久失败/取消后清理对应断点产物。
- FR-004 重启和暂时性错误仍共享三次执行预算，复用也计一次执行；不允许终态回退或查询写入。
- FR-005 老数据兼容；不改变现有HTTP形状；可在执行详情看到恢复阶段。保护已登记断点，不将文件维护当作自动删除登记素材。

## Key Entities
阶段断点：任务、已完成阶段、输入摘要、可选产物位置与摘要、完成时间。

## Success Criteria
- SC-001 整理阶段暂时失败后第二次成功，图片合成调用总计一次。
- SC-002 缺失、损坏和输入改变三种样本均不使用旧产物。
- SC-003 容器全量检查、独立服务真实强杀恢复及最终远端CI通过。

## Assumptions
在现有三个顺序阶段和单实例基础上增量实现；单步内部不做百分比断点；中间文件放共享持久卷，最多保留最近两阶段标记。后续多实例领取单独立项，不引入额外队列服务。
