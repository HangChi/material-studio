# Feature: 账号界面优化
**Created**: 2026-10-30
**Status**: Ready
**Input**: 优化全部账号模块UI，完成提交后关闭项目进程。
## User Scenarios & Testing
### US1 / 访客访问与找回（P1）
访客清楚区分登录、注册绑定与恢复；表单有可见标签、格式帮助、密码显示开关，切换模式清除敏感输入。
验收：登录/注册/找回可键盘到达；显示密码可切换且不提交表单；切换模式重新隐藏；迁移仍需勾选与确认。
### US2 / 账号安全与结果（P1）
已登录用户看到账号摘要与分区安全操作；恢复表单可返回；生成恢复码后必须确认保存才能继续。
验收：退出、重新生成、重置密码有清晰入口；返回取消密码输入；错误和忙碌状态可理解；恢复码仍仅内存一次显示。
## Requirements
- FR-001 延续工作台品牌和导航；账号页桌面双栏、375px单栏，避免横向溢出。
- FR-002 登录、注册、找回、已登录、轮换和成功状态采用一致的标题、说明、表单与操作层级。
- FR-003 密码显示切换不发请求，模式切换清空并隐藏敏感字段；保留自动填充、原验证与防重复提交。
- FR-004 保持账号API、访客迁移确认、身份隔离和恢复码保存门禁。
## Success Criteria
- SC-001 新交互真实RED/GREEN、原账号回归、前端完整容器检查通过。
- SC-002 桌面/375px及找回模式真实浏览器可读、无横向溢出；成功/登录态受控组件验证。
- SC-003 提交推送并检查CI；关闭本项目所有容器/宿主进程，保留数据卷。
## Edge Cases / Assumptions
只改账号UI，不新增账号能力/外部服务。接口错误继续展示；恢复码和密码不写浏览器存储或截图。不同身份继续卸载旧表单。项目进程关闭不包含Docker Desktop或其他项目。
