# Feature Specification: 可回退的实时状态推送
**Created**: 2026-10-30
**Status**: Ready
**Input**: 第10项第三独立增量；多任务状态通过一个持续连接更新，异常回退既有查询。
## User Scenarios & Testing
### US1 合并状态推送（P1）
用户同时观察多项制作，页面建立一个连接接收最新状态；任务完成即停止，离开/换身份即关闭。
验收：初次连接得到最新快照，后续更新只作用于订阅任务；一个任务失败不影响其他任务；终态不回退；他人或无效身份不能订阅。
### US2 中断回退及身份清理（P1）
网络断线、服务不支持推送、返回无效数据或长时间无消息时，自动读取最新状态并继续原有独立查询；查询错误不改写业务失败。
验收：断线立即补查、缺推送能力时仍能用；旧连接数据不能污染新身份；会话失效清空私有状态；页面离开/所有任务结束清理连接和计时器。
### Edge Cases
订阅任务最多50个；每进程同时最多64个连接、每用户最多2个；额满不影响普通查询。心跳和固定最长寿命回收连接，不承诺每个中间状态都到达，重连/回退读取当前权威快照。
## Requirements
- FR-001 每个跟踪器将活动任务合并为一个订阅；初始返回当前快照，任务ID和归属全部校验，禁止混入其他任务数据。
- FR-002 继续按任务版本拒绝过期响应、终态回退和旧身份数据；查询与执行错误分别管理。
- FR-003 断线、无效消息、20秒无可观察消息时回退查询；补查不重发制作。推送不可用时保持原查询功能。
- FR-004 服务周期重验会话，撤销后通知失效并关闭；终态/离开/超时回收，连接限额有明确错误。
- FR-005 支持现有代理和多个后台，不新增共享消息服务；不在响应/URL泄漏Cookie或内部路径。推送只读，不推进任务。
## Key Entities
订阅：当前身份、任务集合、最新版本快照、活动连接与期限；客户端跟踪生命周期：身份/版本/回退状态。
## Success Criteria
- SC-001 两项活动任务共享一个连接，初始/更新/终态正确，静默时不产生逐项HTTP查询。
- SC-002 无权限订阅全拒绝，撤销会话及换身份后零私有旧快照。
- SC-003 断线、无效消息、静默超时三种情况均补查成功；页面退出后无残留客户端连接/定时器。
- SC-004 容器前后端全量、真实代理流/断连/身份、浏览器桌面375px和最终远端CI通过。
## Assumptions
基于013；服务仍每秒从持久状态生成快照，此次减少客户端HTTP轮询请求，不声称减少所有数据库查询。事件详情仍保留独立历史接口，流仅保证最新快照。无WebSocket/MQ/Redis或生产流量SLA。
