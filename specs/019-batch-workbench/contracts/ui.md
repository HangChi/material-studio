# UI Contract
- HTTP/请求体/幂等键、批次/任务快照、账号归属沿用011/016/018，无新字段。
- 制作项的模板/移除按钮仍有“制作项 N 模板”“移除制作项 N”的唯一可访问名称。
- 只有一个“提交批次”按钮，所有项目就绪时启用；busy/unknown沿用fieldset禁用，不允许不确定结果下另行提交；安全重试使用原key/body。
- 素材准备进度为progress[aria-label="素材准备进度"]，value就绪项目数/max总项目数；与后台阶段独立。上传位仍具有原校验/预览/替换/错误/素材库行为。
- 历史查询状态与制作失败分开；无历史时显示可理解空态，分页和取消不变。
