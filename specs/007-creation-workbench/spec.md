# Feature Specification: 制作工作台拓展

**Feature Branch**: 沿用当前分支；feature目录独立编号007
**Created**: 2026-10-29
**Status**: Implemented and locally validated
**Input**: 用户要求全部实现两处所选建议：提交幂等、失败重试、任务事件详情、下载、再次制作、真实明信片合成与模板参数化。

## User Scenarios & Testing

### US1 - 安全重试提交 (P1)
用户丢失受理响应后可重试同一次操作，无需人工判断是否已创建。
验收：同身份同操作相同内容（含并发）只产生一个任务和一次调度；改变内容冲突；不同身份互不影响；刷新后仍可恢复未确认操作；明确参数错误可修改后重新提交。

### US2 - 下载与重新制作 (P1)
用户可下载自己的成功作品，复用原素材再次制作，或重试失败任务。
验收：新任务关联原任务，复用素材及制作参数，清除模拟失败设置；旧任务及结果不变；仅终态可重新制作；素材失效清晰报错；丢失响应可安全重试；其他身份无法读取或重新制作。

### US3 - 执行详情 (P1)
用户展开任务查看阶段开始、完成、失败时间和原因。
验收：记录按事件顺序显示；查询失败只影响详情并可重试；活动任务版本变化时更新已展开详情；关闭/离开/换身份取消查询；无事件有明确空态。

### US4 - 可配置真实明信片 (P1)
用户上传两张图片，调整裁剪位置、放大、标题、配色、比例，预览构图并生成真实作品。
验收：不同输入图片确实改变结果；裁剪设置反映到输出；标题包含中文也可正常呈现；横版1200×800或方版1000×1000，支持奶油/海蓝配色；非法参数拒绝且不创建任务；再次制作保留参数；不传参数有默认值；其他模板继续支持模拟制作。

### Edge Cases
网络中断、无效响应、相同操作不同内容、并发提交、身份切换、浏览器存储不可用、旧版任务无参数、素材丢失、结果丢失、事件读取错误、长标题、非法数值/字段、非终态重试均需明确反馈。

## Requirements

### Functional Requirements
- FR-001：操作标识在本人范围内持久去重，内容冲突不能静默创建。
- FR-002：未确认提交允许复用原操作安全重试，刷新恢复；更改输入不得覆盖未确认操作。
- FR-003：重试/再次制作产生新任务，保留原记录、素材顺序与制作参数，并去掉强制模拟失败。
- FR-004：成功结果可按本人权限下载PNG，错误不能伪装成成功下载。
- FR-005：阶段详情独立显示开始/完成/失败/中断及时间；错误不修改任务状态。
- FR-006：明信片使用两张原图真实合成；支持标题、配色、比例、每图裁剪位置及放大，实时展示构图预览。
- FR-007：制作参数持久化，后台执行与前端预览使用同一裁剪定义，非法参数在受理前拒绝。
- FR-008：保留匿名身份隔离、异步状态生命周期、原三阶段与可控失败机制，单智能体SDD+TDD容器验证。

### Key Entities
- 制作配方：标题、配色、比例、两张图的裁剪参数、原任务关联。
- 受理操作：本人操作标识、内容摘要、对应任务。
- 阶段事件：已有事件的顺序、阶段、类型、发生时间、说明。

## Success Criteria
- SC-001：同一操作并发重复提交只创建1项任务并仅调度1次；内容冲突返回可理解错误。
- SC-002：成功/失败原任务各能产生关联的新任务，原记录不变，强制失败重试可成功。
- SC-003：本人PNG下载内容与结果一致，其他身份读取/重试/详情均被拒绝。
- SC-004：两种比例、两种配色及裁剪变化通过输出像素/尺寸测试证明；中文标题无缺字。
- SC-005：前端覆盖安全重试、详情错误恢复、参数提交、多任务及身份隔离；容器全量检查通过才标完成。

## Assumptions
沿用现有匿名身份与单工作线程；真实合成只扩展明信片；重试从第一阶段重新执行，不做断点续跑；无需真实AI或外部服务。浏览器本地只存本人未确认操作的素材ID/参数，不存身份令牌；无法存储时明确提示刷新恢复限制。
