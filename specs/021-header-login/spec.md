# Specification: 右上角登录与账号页整理
Created: 2026-10-30 · Status: In progress
用户要求账号页继续优化，并改为右上角登录入口。
- FR-001 主导航只保留三个制作入口；全站右上角独立账号入口，游客显示“登录”，已有账号显示用户名，均进入/account。手机首行品牌/登录，第二行导航，无横向溢出。
- FR-002 入口只GET读取已有会话，不创建访客或撤销会话；401/读取失败保留可用登录链接。路由改变、跨标签身份通知与当前页账号成功操作后更新，不显示旧请求返回的用户名；卸载取消请求。
- FR-003 账号页集中为一个表单区域，去掉重复的“账号”标题和说明，动态主标题明确登录、注册、恢复或已登录用户。保留全部密码限制、显式迁移确认、恢复码保存门禁与本地草稿说明。
- FR-004 当前页通知仅更新右上角展示，不重新挂载账号表单，不丢失仅显示一次的恢复码；其他身份隔离、接口和权限沿用018。
验收：入口行为先RED/GREEN，完整前端容器检查，1280/375px真实浏览器登录入口/账号表单与导航验证，服务保持运行。无Java、数据库或依赖变更。
