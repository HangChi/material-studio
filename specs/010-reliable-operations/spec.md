# Feature Specification: 制作可靠性与交付验证

**Created**: 2026-10-29
**Status**: Approved for implementation
**Input**: 实现执行顺序1～5；创建新的公开仓库并运行远端CI。

## User Scenarios & Testing

### US1 · 可复现交付（P1）
维护者能从空数据环境启动、运行远端检查，并核对真实双标签身份清理与高对比模式。
独立验收：独立数据环境完成成功闭环，公开仓库流水线通过；两个标签切换后同归新身份，高对比模式控件可用。

### US2 · 安全切换访客（P1）
访客在放弃当前身份前确认不可找回的后果。取消保留原身份与记录；确认后只切换一次，后台任务继续。
独立验收：取消零撤销请求；确认一次撤销；键盘能操作并有焦点。

### US3 · 模板筛选一致（P1）
历史记录筛选展示当前可用模板，新增模板不要求同时修改历史界面。
独立验收：额外模板可以选择并筛选；加载失败可重试，保留其他筛选和记录访问。

### US4 · 持久排队和受理保护（P1）
执行容量满时，已受理任务保持等待并最终执行；超过配额时明确拒绝且不产生任务。重复确认同一操作不消耗新配额。
独立验收：超过内存等待容量仍全部最终完成且不重复；并发提交不突破总配额；速率限制不影响既有任务查询/执行；终态释放待办配额。

### US5 · 异步运行监控（P2）
维护者可在内部监控入口检查等待/处理中数量、排队与阶段耗时、成功/失败数量与失败率、重试次数、扫描失败次数。监控不得泄漏身份、任务ID、文件位置或对浏览器暴露全局数据。
独立验收：受控成功/失败/重试记录产生可核对的统计；无完成样本不出现除零/NaN；扫描故障计数且恢复后继续扫描。

## Requirements
- FR-001 独立环境与现有演示数据隔离；CI运行来源、结果和限制如实记录。
- FR-002 身份切换需明确确认；取消不发出撤销请求，不清理当前视图。
- FR-003 历史模板选项由当前模板数据提供；提供加载、错误重试及卸载清理。
- FR-004 已持久受理任务不得因内存队列满或关停窗口变为队列失败；调度暂不可用由后续扫描恢复。
- FR-005 默认全局未完成任务上限100、单访客上限20、每访客每60秒最多10个新任务；全部可配置。超过任一项返回明确拒绝，既有幂等回放先于配额检查；同一短事务保证并发不超额。
- FR-006 配额拒绝不得写入任务、素材关联、配方或提交回执；支持停止后恢复待办，查询不推进任务。
- FR-007 内部监控提供当前任务计数、排队时长和阶段耗时、终态失败率、重试执行数、扫描错误数；定义样本与重启边界。
- FR-008 保持匿名归属、三阶段顺序、有限重试、取消、结果读取与前端查询错误隔离。

## Key Entities
- 受理配额：全局及访客未完成数量、访客最近一分钟新增任务数量。
- 运行统计：任务状态数量、执行事件的耗时样本与后台扫描错误计数。

## Success Criteria
- SC-001 空数据启动和公开仓库两项CI均有真实结果，现有数据不丢失。
- SC-002 取消切换后原记录仍可见；确认后两个标签不再显示旧身份数据。
- SC-003 添加额外模板选项无需修改历史页；错误后可恢复加载。
- SC-004 内存等待容量1时连续受理至少6个任务全部完成且各执行一次；超过受理上限的并发请求不产生额外任务。
- SC-005 监控的受控样本数量、耗时和失败比例与已保存记录一致；浏览器无法读取全局监控。

## Edge Cases
双击确认、取消后重试、模板请求迟到/失败、幂等回放时已满配额、事务回滚、并发不同用户、关停时受理、无监控样本、重复阶段/重启、扫描数据库不可用。

## Assumptions
保持单后端实例；限额是演示默认值，不增加账号体系。失败率将用户取消单列，自动重试按额外执行次数计数。监控面向维护者，无新业务仪表盘；不引入外部监控服务。公开仓库名称默认material-studio，若已占用则使用material-studio-xiaoying。
