# Specification: 制作记录筛选与批量管理界面
**Created**: 2026-10-30
**Status**: Complete (container and browser validated)
**Input**: 用户截图指出筛选与批量管理占位过大、按钮堆叠，要求优化页面。

## Requirements
- FR-001 常用搜索、模板和状态在一行组织，日期与标签放入可展开的更多筛选；展开/收起保留输入，应用与重置沿用原筛选行为。
- FR-002 收藏/隐藏为清晰的选项，已应用的筛选数量可见；重置同时清空常用及更多条件。
- FR-003 无作品时不显示无效批量工具；有作品未选择时仅显示紧凑选择入口和说明，选中后展示收藏/隐藏/恢复/ZIP操作，标签编辑按需展开。
- FR-004 批量50项、ZIP20项且仅成功结果、标签覆盖提示、请求中禁用、错误和身份过期处理保持。取消选择和操作完成后焦点返回稳定控件。
- FR-005 沿用工坊绿与纸白品牌，控件至少44px、可见标签/焦点和语义展开状态；桌面与375px无横向溢出，空态/选中态/展开态均需实际查看。

## Acceptance
新增行为先RED后GREEN，既有筛选/批量/身份/查询回归通过；纯布局通过浏览器截图确认。完整前端lint/typecheck/test/build通过，重建当前运行前端供用户查看，不关停用户已启动的项目。
