# Plan: 紧凑的作品整理工作台
## Context / Constitution
基于011作品组织、016修复后的项目，约章1.2.0 I～V检查通过，单智能体串行。无新依赖、后端接口/数据库变更；业务状态仍由原History/JobTracker管理。
## Design
配色：工坊绿#286353、墨色#29332f、次级文字#62716a、画布#f7f8f7、纸白#ffffff、分隔#e0e5e1，全部复用现有token。字体沿用系统中文黑体，标题20～30px、工具文案12～14px、计数用monospace。
布局比较：全部字段网格造成日期跨行；改为“主筛选一行 + 下方选项 + 可展开细节”，主次清楚。批量区从大卡片改为随选择展开的操作带，左侧选中计数是唯一强调点。避免增加统计卡片、装饰大标题或浮动遮挡内容的底栏。
History负责更多筛选显隐/计数和布局，BulkControls负责空/未选/已选展示；原请求逻辑不变。样式放到history.css并由记录页面导入，避免继续堆叠全局覆盖。复用StudioIcon，补搜索、选择、收藏等线性图标。
## Verification
更多筛选保值/应用/重置、未选不展示批量动作、选中展现/标签操作/清空与焦点、空作品不展示管理、下载资格回归。容器运行；浏览器桌面与375px实际截图，保留服务运行。
