# UI Contract
HTTP与payload沿用011/016，无新增接口。
- 更多筛选按钮aria-expanded/aria-controls关联隐藏容器；日期和标签输入保持挂载，收起不清除。应用筛选仍提交完整form，重置清空并收起更多条件。
- 保留搜索作品、模板、任务状态、标签筛选、开始日期、结束日期、只看收藏、查看已隐藏作品的可访问名称。
- 已应用筛选数只由应用后的filter计算，草稿条件不冒充已应用。
- 批量管理仅有已加载作品时出现；零选择隐藏执行区，1～50选择展开；标签覆盖规则明示。原批量动作可访问名称及归属校验、限额不变。
- 下载仅1～20个成功任务启用，失败/处理中解释原因；网络失败保留选择及错误，成功清空选择并回到稳定选择按钮。
