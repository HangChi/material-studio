# Specification: 全站界面减法
Created: 2026-10-30 · Status: Complete (container and browser validated)
用户要求整体去掉AI味。范围为模板库、制作、记录、批次、账号及公共导航。
- FR-001 标题与说明直接描述用途，删除宣传口号、账号插画、装饰箭头和重复图标。
- FR-002 统一克制的字号、留白、边框与圆角，消除大屏模板页空白；保留照片与制作结果的视觉重点。
- FR-003 账号为单列表单，保留注册绑定说明、显式迁移、恢复码保存和全部安全限制。
- FR-004 上传、身份隔离、提交/重试、筛选、多选、准备进度与后台状态行为保持现有契约，无API、数据库结构、依赖变更。
- FR-005 桌面1280和手机375px无横向溢出，保留语义名称、键盘焦点与主要触控尺寸。
验收：全前端容器检查，真实浏览器五类页面桌面/手机目视验证。纯文案/样式不强造RED，现有行为测试回归。模板名称、样张与作品内艺术文案保留；三条内置模板说明改为用途描述，以新增V16迁移更新，旧迁移保持不变。
