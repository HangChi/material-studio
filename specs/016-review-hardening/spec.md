# Specification: 审查问题逐项优化
**Created**: 2026-10-30
**Status**: Complete (local container validation)
**Input**: 用户要求逐个优化代码审查中的三个功能问题及查询、可维护性、测试建议。

## Requirements
- FR-001 批次取消与子任务结束并发时，保留已结束任务，取消剩余活动任务，不因预期终态冲突回滚整批。单任务终态取消仍返回409，归属校验不变。
- FR-002 批次列表请求发起后新受理的批次不能被旧响应移除；分页顺序、去重、刷新重置游标和身份隔离保持。
- FR-003 移除最后一张素材或将参数恢复默认后，持久草稿反映当前空状态，刷新不能复活旧选择；显式清空、提交中和结果未知的保护保持。
- FR-004 批次列表按批量读取子任务，保持批次顺序和素材槽位顺序、本人归属、状态及元数据字段；查询次数不随批次和子任务数量逐项增长。
- FR-005 基于MySQL EXPLAIN核对调度与排队统计查询，添加必要索引；已应用迁移保持不可变。
- FR-006 在本次修改的事务、列表合并和查询路径展开步骤、提取职责明确的小函数；不引入额外服务或通用框架。

## Acceptance
三个原始缺陷均有先失败再通过的永久回归测试；单任务取消/批次权限与分页、前端既有交互回归通过。批量读取验证多批次、多项、顺序与隔离；记录查询数和EXPLAIN证据。最终容器前后端完整检查通过，更新README和工作日志，逐项提交，不发布或启动长期服务。
